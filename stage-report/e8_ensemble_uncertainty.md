# E8 · 從別的領域借一個訊號：用種子間的分歧取代模型信心

2026-08-19 設計。**不需要訓練**，重用既有的 12 顆 STARE 檢查點，只做推論。

E1' 留下一個沒解決的問題：模型的逐像素信心在最需要它的地方是反的。
本報告記錄一次跨領域的搜尋（機器人、連接體學、遙測、大語言模型），
以及從中挑出的唯一一個**現在就做得起**的實驗。

---

## 0. E1' 留下的洞

E1' 量到的：模型猶豫度預測人類標註分歧的 AUROC，
在最亮的一層是 0.881，在最暗的一層是 **0.373**——低於 0.5，代表方向相反。
而最暗那一層裝著 45.6% 的標註分歧。

機制也量到了：爭議像素上模型輸出 p=0.203，無爭議像素上輸出 p=0.574。
也就是說，**模型對它漏掉的暗血管很有信心。**
這不是校準不良（calibration，指信心數值與實際正確率不匹配），
是訊號本身在該區域帶著錯誤的方向。

E7 繞過它——改用影像對比當權重，不碰模型信心。
E8 直接面對它：**換一個不確定度訊號。**

## 1. 跨領域搜尋

查了四個和我們沒有引用關係的領域，找可以搬過來的想法。

### 1.1 大語言模型的幻覺偵測 → 這次採用的

LLM 領域撞到過同一堵牆，而且結論一模一樣：
**post-softmax 機率不可靠。** 他們的解法是不要問模型有多確定，
而是**多採樣幾次，量答案之間的分歧**（semantic entropy，Nature 2024）。
模型不確定時，多次生成的語意會發散；確定時會一致。

搬到分割上，「再採樣一次」的對應物是「換一顆種子再訓練一次」。
**我們已經有了**——每個 STARE 設定都有 seed 0 和 seed 1。
所以這個實驗的成本是推論，不是訓練。

關鍵在於：兩個模型可以**都很有信心、而且都錯**，
但只要它們錯的方向不同，分歧就看得見，信心看不見。
E1' 量到的正是「有信心地錯」，所以這正好是對症的訊號。

誠實的定位：深度整體（deep ensemble）當不確定度在醫學影像是**老東西**，
E8 不宣稱方法新。新的是問題——
**它能不能修好「信心在特定對比層反轉」這個特定的失效？**
沒人問過，因為沒人依局部對比分層。

### 1.2 遙測的道路網擷取 → 最值得記下來的架構想法，但現在做不起

[RoadTracer（CVPR 2018）](https://roadmaps.csail.mit.edu/roadtracer/)
放棄「逐像素分割再後處理接起來」，改成一個 agent 從起點開始，
每一步用 CNN 決定往哪個方向走，**直接長出圖（graph）**。
他們給的理由和我們量到的一字不差：
「先前工作用 CNN 偵測哪些像素屬於道路，再用複雜的後處理啟發式推斷連通性；
這些方法錯誤率高，因為**有雜訊的 CNN 輸出很難事後修正**。」
在 5% 錯誤率下，路口的捕捉率比分割法高 45%。

我們的 stage 0 + E4 是同一件事的量化版：
連通塊過濾（一個後處理啟發式）買到的 β₀ 改善是拓樸 loss 的 2.4–2.6 倍。
換句話說，**我們的模型輸出爛到後處理比改 loss 更有用**——
這正是 RoadTracer 說「該換範式」的那個症狀。

為什麼不現在做：一個 MDP agent 不是六核 CPU 筆電上十小時能訓練的東西。
記在這裡，等有 GPU 再說。

### 1.3 連接體學的神經元重建 → 同一個想法的第二次獨立發生

[Flood-Filling Networks（Nature Methods 2018）](https://www.nature.com/articles/s41592-018-0049-4)
在電子顯微鏡神經元重建上做了結構上相同的事：
一個帶遞迴路徑的 CNN，把「目前這個物件的預測遮罩」也當成輸入，
反覆迭代把物件從邊緣長出去。誤差路徑長度比當時的方法好一個數量級。

兩個毫無往來的領域（遙測、腦神經）**各自獨立**放棄了密集逐像素預測，
理由都是拓樸錯誤無法事後修。這種獨立重複發生比任何單篇論文都值得注意。

而且 FFN 自陳的弱點是：
「目前的分割演算法在**低對比、低解析度或有影像瑕疵的區域**泛化很差。」
那是我們 E2 量到的東西，換一個領域的語言講出來。

**可以現在做的降級版**：把目前的預測當成額外輸入通道回饋給同一個 TinyUNet，
跑 N 次迭代——FFN 的遞迴路徑，去掉強化學習。
一個額外通道，架構不變，成本幾乎不變。
但「視網膜血管的迭代精修」文獻上已經有人做（含對抗式 + 遞迴單元），
所以這一格是擠的，優先度低於 E8。

### 1.4 機器人學的地圖表示 → 一個框架，不是一個實驗

機器人導航刻意**同時維護兩種地圖**：
度量式的佔據網格（occupancy grid，精確、局部）
和拓樸圖（topological map，粗略、全域、連通性正確），
然後在圖上做路徑規劃。

搬過來就是：**不要要求同一個網路同時在像素層級和拓樸層級都正確。**
1.2 和 1.3 都是這個框架的實例。

另外一條線索：閉迴路偵測（loop closure）在機器人學就是 β₁ 問題，
而且有一整套「什麼時候該相信一個迴路」的方法。

（**2026-08-20 更新**：這裡原本寫「E4 量到 β₁ 的行為和 β₀ 相反，我們還沒解釋」。
[[e9_hole_sweep]] 已經解釋掉了，而且推翻了 E4 那個 15 倍——
它是拿「換 loss」去對上「移除連通塊」，而移除連通塊在構造上碰不到 β₁。
換成對偶工具（填補小洞）之後，TopoMortar 上 loss 之間的差距一格就塌掉。
機器人學那條線因此不再是唯一的線索，但「什麼時候該相信一個迴路」
對樹狀結構那半邊——模型**缺**迴路、後處理生不出來——可能仍然有用。）

### 1.5 順手做的鄰近工作查核（E6 有沒有被撞到）

搜尋過程中撞到兩篇看起來會撞 E6 的，按 E0 的規矩讀進實驗設定確認：

| 論文 | 它做的 | 有沒有撞到 E6 |
|---|---|---|
| [Confidence Aggregation 基準（arXiv:2406.03323）](https://arxiv.org/html/2406.03323v1) | 把逐像素信心聚合到**整張影像**做失敗偵測 | 沒有。聚合的目標層級不同（影像 vs 分支），資料是團塊器官與病灶（腦瘤、心腔、攝護腺、肺病灶、腎腫瘤），**沒有管狀結構**，沒有等大對照組，沒有對比分層 |
| [Structure-Wise Uncertainty（arXiv:2211.00303）](https://arxiv.org/abs/2211.00303) | 逐體素與逐影像之間的中間層級 | 沒有。結構＝腫瘤/病灶這種局部團塊，不切骨架交叉點，沒有等大對照 |

第一篇還幫了一個忙：他們明說
「mean aggregation 可能只是因為物件大就得到較高的不確定度」，
但**只用邊界遮罩處理，沒有做受控消融**。
E6 的等大等位置對照組量的正是那個東西，而且量出來的答案是
「在暗處，功勞完全屬於聚合，不屬於結構」。
所以 E6 不但沒被撞到，還補上了他們自己指出卻沒測的洞。

## 2. 設計

三個訊號，同一批像素，同一個 AUROC 評估流程（直接沿用 E1' 的 `auroc()`，
已對過 sklearn 到小數 6 位），所以數字和 `stare_hesitation.csv` 可以直接比。

| 訊號 | 定義 | 角色 |
|---|---|---|
| `single` | 單一模型的猶豫度 `1 − 2|p − 0.5|` | E1' 重現 |
| `ens_mean` | **平均**機率圖的猶豫度 | 關鍵對照 |
| `disagree` | `|p_seed0 − p_seed1|` | 主張 |

`ens_mean` 是這裡的支點，理由和 E7 的 `G_focal` 一樣：
如果整體只是靠「平均後的機率圖比較平滑」而變好，
那這是校準問題，不是分歧問題，semantic entropy 的類比就不成立。
少了這個對照，`disagree` 贏了也解讀不了。

兩顆種子偏少（分歧只有一個 `|p0 − p1|`），這是資料現況的限制，
不是設計選擇。用全距（range）而不是標準差寫，是為了加第三顆種子時定義不變。

## 3. 機制驗證（已完成）

`exp/ensemble_uncertainty.py --selftest`，在合成資料上建出實驗要找的那個情況：
兩個模型在爭議像素上**都很有信心、但方向相反**（0.05 對 0.95），
在其他地方都停在 0.5 附近。

```
confidently-wrong-in-opposite-directions case: single 0.000, ens_mean 1.000, disagree 1.000
agreed-and-both-wrong case: disagree 0.509 (blind, as it must be)
```

三件事被證實：

1. **`single` 得到 0.000**——E1' 的反轉在合成資料上被構造性地重現。
   信心把爭議像素排在無爭議像素**之下**，正是實測 0.373 的極端版。
2. **`disagree` 得到 1.000**，符合預期。
3. **`ens_mean` 也得到 1.000。** 這一條最重要：
   0.05 和 0.95 平均起來剛好是 0.5，看起來「最猶豫」。
   所以合成資料**分不開** `ens_mean` 和 `disagree`——
   這正是為什麼它必須留在實驗裡，而不是可以省掉的裝飾。

第二個檢查是反向的：兩個模型**一致地錯**時，`disagree` 得到 0.509，
也就是瞎的。這是刻意寫進斷言的——
分歧不是正確性偵測器，讀者若當它是就會過度解讀結果。

## 4. 結果（2026-08-20）

跑完之後加了第四組。原設計只比「同一設定的兩顆種子」，
但拿到負面結果後有一個明顯的追問：
失敗是因為**分歧這個訊號沒用**，還是因為**這兩個成員太像**？

STARE 手上剛好有一種不會太像的成員：一個用 ah 訓練、一個用 vk 訓練。
所以多跑一組 `annotator` 成員（`|p_ah − p_vk|`），共 400 列。

**這一組必須小心讀，它不是通用方法**：它要求訓練時就有兩位標註者，
而那正是稀缺的東西；而且有部分循環性——用 ah 訓練的模型本來就偏向 ah。
它在這裡是回答另一個問題：**關於爭議像素的資訊，到底學得到還是學不到？**

### 兩組成員，AUROC 依對比層

| 對比層 | seed: single / ens_mean / disagree | annotator: single / ens_mean / disagree |
|---|---|---|
| Q1_dimmest | 0.386 / 0.373 / **0.380** | 0.280 / 0.370 / **0.390** |
| Q2 | 0.591 / 0.597 / 0.583 | 0.429 / 0.625 / **0.632** |
| Q3 | 0.766 / 0.775 / 0.745 | 0.672 / 0.813 / **0.805** |
| Q4_clearest | 0.872 / 0.882 / 0.848 | 0.869 / 0.895 / 0.879 |

（兩欄的 `single` 不同是因為它取成員的第一顆：
seed 組是該設定自己的模型，annotator 組固定是 ah 模型。）

逐格勝負（`disagree` 贏過 `single` 的格數）：

| | Q1 | Q2 | Q3 | Q4 |
|---|---|---|---|---|
| seed | 24/60 | 25/60 | 11/60 | 13/60 |
| annotator | **39/40** | **40/40** | **40/40** | 26/40 |

### 三個結論，按確定性排序

**一、種子分歧沒用。** Q1 從 0.386 到 0.380，逐格 24/60，
在亮處甚至比單一模型差（Q3 11/60、Q4 13/60）。

**二、成員的多樣性種類決定一切，而且分歧確實承載真資訊。**
換成標註者成員之後，Q2 從 0.429 跳到 0.632、Q3 從 0.672 跳到 0.805，
而且是 40/40、40/40 的全勝。
所以「量成員之間的分歧」這個想法本身沒有錯——
錯的是拿兩顆只差初始值的種子當成員。
兩顆種子看同一批資料、同一個 loss，養出同一套偏誤；
換初始值改變的是雜訊，不是偏誤。

**三、但最暗的那一層，連標註者成員也修不好。**
Q1 的 annotator `disagree` 是 **0.390——仍然低於 0.5，仍然是反的。**

第三點是這個實驗真正的收穫，機制數字說得很清楚
（`disagree` 在爭議像素 / 無爭議像素上的平均）：

| 對比層 | seed | annotator |
|---|---|---|
| Q1_dimmest | 0.1171 / **0.1821** | 0.2467 / **0.3587** |
| Q2 | 0.1499 / 0.1171 | 0.4086 / 0.2740 |
| Q3 | 0.1265 / 0.0501 | 0.3978 / 0.1174 |
| Q4_clearest | 0.0851 / 0.0145 | 0.2425 / 0.0258 |

Q2 以上，兩組都是「爭議 > 無爭議」，方向正確。
Q1 兩組都反過來：**在最暗的一層，兩個模型在人類吵架的像素上反而比較一致。**

連「一個學 ah、一個學 vk」的兩個模型，
都不在兩位標註者真正分歧的地方分歧。

### 這換到了什麼

一個比原本更緊、也更有用的約束：

> **在最暗的一層，模型對有爭議的像素比對無爭議的像素還要有把握，
> 而且這個把握在換種子、換標註者、取平均之後都不變。**

（初稿在這裡寫的是「模型根本沒有表示那些血管」。**那句話比量到的東西強，已改掉。**
量到的是猶豫度：Q1 有爭議像素的平均猶豫度 0.1449（標註者成員 0.0634），
無爭議像素 0.1930（0.1522），也就是 `|p − 0.5|` 平均至少 0.43 與 0.47——
**很有把握，而且對爭議像素更有把握**。E1' 另外量到那個把握指向背景（p=0.203）。
但「模型內部有沒有編碼那些血管」是另一個問題，本實驗沒有量，不能宣稱。）

`ens_mean` 對照組在這裡也拿到它該拿的：
它在亮的幾層普遍贏過單一模型（Q3 0.813、Q4 0.895），在 Q1 依然是 0.370。
平均只是把已經對的地方修得更準，沒有在失效處帶進新資訊。

所以路線很明確：**要修 Q1，必須改變模型學到什麼，
而不是改變怎麼讀模型的輸出。** 任何讀出方法——信心、種子分歧、
標註者分歧、平均——在 Q1 都撞到同一堵牆。

這把 E7 的動機從「E1' 的一個觀察」升級成
「四種讀出方法試過，全部在同一層失效」。
E7 動的正是模型學到什麼（在暗處加大拓樸壓力），
是這個結果剩下的那條路。

### 自我檢定預先寫好的兩種情況

```
confidently-wrong-in-opposite-directions case: single 0.000, ens_mean 1.000, disagree 1.000
agreed-and-both-wrong case: disagree 0.509 (blind, as it must be)
```

真實資料在 Q1 落在第二種（一致地錯），在 Q2–Q4 落在第一種。
當初把兩種都寫成斷言而不是註解，現在直接就是解釋，不必事後編故事。

### 沒有做的

原本計畫「若逐像素修好了就接上 E6 的分支聚合」。既然沒修好，就沒做。
另外沒排除的是成員數：兩顆偏少。但 Q1 的方向是**反的**而不是弱的，
加成員通常不會把方向轉過來，而第三點也給了一個更根本的理由。
