# stage-report · 索引

視網膜血管分割（以及更廣義的曲線結構分割）的一系列實驗。
全部在一台六核筆電上以 CPU 跑完，沒有 GPU。

閱讀順序：**stage_0 → stage_1 → E0 → E2 → E3'/E1' → E6 → E4 → E5 → E7 → E8 → E9 → E9b → E10 → E11 → E12**。

E0 到 E6 都是量測，E7 是第一個動模型的實驗。

## 這一系列真正學到的東西

六件比任何單一數字都重要的事：

**一、單一平均指標會系統性地隱藏方法差異。**
E2 在 DRIVE 上、E4 在 TopoMortar 上、E6 在不確定度上，
三次看到同一個模式：一個總數把兩個方向相反的效應平均掉。
分層報告的成本是零。

第四次出現在 E9b 自己身上，而且是當天早上寫的報告：
HRF 的整體迴路缺口是 −40.7，看起來焊接理所當然該有效。
拆開來是**健康影像 +1.3、病變影像 −56 到 −67**——
健康視網膜的模型根本沒有缺口，焊接在那裡是有害的（4/5 張變差，p = 0.017）。
修正後的說法：**有缺口時焊接有效（三個資料集都複製，−4.7 到 −13.6），迴路數接近正確時有害，過多時中性**。
這條規則是**逐影像**的：TopoMortar 整體方向相反，它自己的 89 個深缺口單位仍然改善 −6.8。

**二、加一個控制變項，經常會翻掉原本的解讀。**
本系列有五次自我推翻：
stage 0 的「clDice 免費獲勝」被連通塊過濾推翻；
E3' 的「用 vk 訓練拓樸較好」被骨架精度推翻；
E6 的「結構層級救回了暗處」被等大對照組推翻；
E4 的「β₁ 上 loss 贏過濾 15 倍」被 E9 的填洞掃描推翻；
E9 的「β₁ 只能從模型端修」被 E9b 的焊接掃描推翻——**同一天內推翻自己**。
每一次都是加一個對照，不是換一個模型。

第四、五次合起來給了一條可操作的規則，而且第五次示範了它多容易套錯：
**每一個拓樸指標的每一個方向都有對應的後處理操作，要先排除，宣稱才站得住。**

| | 太多 | 太少 |
|---|---|---|
| β₀（連通塊） | 移除小連通塊 | 焊接斷口 |
| β₁（迴路） | 填補小洞 | 焊接斷口 |

E4 只掃了左上一格就對兩個指標下結論；
E9 補了左下一格，卻把「移除型不行」推廣成「後處理都不行」；
E9b 補上右邊那一欄，推翻 E9。**規則寫對了，套用時漏掉一半的操作空間。**

**三、模型端的訊號會一起瞎。**
E1' 量到逐像素信心在最暗的一層反向失效（AUROC 0.373）。
E8 換了三種讀出方法——平均、種子分歧、不同標註者訓練的模型之間的分歧——
在 Q2 以上都有效，**在最暗那一層全部仍然反向**。
換讀出方法救不了，只能改模型學到什麼。

**四、統計單位是「訓練」，不是「影像」。**
E5 用 700 個 (影像, 種子) 配對算出 p = 3×10⁻⁴，
而那個差值在僅有的兩顆種子之間符號相反（−0.0271 / +0.0102）。
700 對來自 **2 次訓練**；配對檢定量到的是「同一個模型在不同影像上表現一致」，
不是「這個 loss 比較好」。這叫**偽重複**，而且 √n 會放大它：
同樣的種子間偏移在 n=60 只給 |t| = 0.99，在 n=700 給 |t| = 11.9。
**n 愈大，錯的方法愈自信。**
配對仍然值得做（它移掉影像難度的變異），但不能單獨成立——
現在的規矩是配對檢定「且」每顆種子符號一致，
已寫進 `summarize_gated.py` 的事前判準，在 E7 結果出來前裝上。

**五、「量到的性質」和「介入的效果」是兩回事。**
E1' 量到模型對自己漏掉的暗血管很有信心（AUROC 0.373）。那個量測完全正確，而我把它當成了「別用信心當訓練訊號」的禁令，寫進 E7 的整個假設。
錯在：那是一個描述**收斂後**模型的量測，不能用來預測一個在**每一步**改變優化路徑的介入。
診斷描述的正是那個訊號要去修的病。
附帶的一條：**控制組要當成真的實驗來設計**——`G_focal` 只是為了讓判準 3 有東西可比才存在，現在它是本系列最好的模型端結果。

**六、先查文獻再設計實驗。**
stage_1 初版規劃的五個實驗有兩個撞到既有工作，
直接開跑會浪費約 22 小時運算並得到沒有貢獻的結果。
但 E0 也補上後半句：**查到撞題不要直接放棄，要讀進實驗設定確認撞的是哪一塊**——
那兩篇在摘要層級看起來重複，在實驗設定層級其實互補。
