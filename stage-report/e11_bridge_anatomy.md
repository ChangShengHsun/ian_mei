# E11 · 焊接到底修好了什麼

2026-08-20。只需推論，用既有的 12 顆 DRIVE 檢查點，與 E9b、E10 疊在同一組後處理之上。

E9b 量到 `bridge_only` 補回 9–30% 的迴路缺口，然後這樣解釋自己的天花板：

> 剩下的 82–91% 焊接搆不到——那些是比兩倍血管寬還大的斷口，
> 或是根本沒被偵測到的血管。

那句話從來沒被量過，而且它是**從斷口長度推論的**——
正是 [[e10_break_anatomy]] 隔一份報告就推翻掉的那個量。
E10 從長度分布預測半徑 6 應該關掉 76% 的斷口，實測 14.9%，差五倍。
所以 E9b 對自己天花板的解釋，靠的是同一系列裡剛剛失效過的同一種推理。

三個預測在跑之前就寫進 `exp/bridge_anatomy.py` 的模組說明：

| | 預測 | 結果 |
|---|---|---|
| **P1** | 焊接對「真切斷」的斷口有選擇性 | **成立** |
| **P2** | 被解決的切斷數應該對得上 β₀ 誤差的改善 | **成立，比預期準得多** |
| **P3** | 分類比長度更能預測解決與否 | **不成立。長度贏。我的假說錯了** |

---

## 1. P1：焊接確實只對切斷的斷口有作用

E10 的分類：把斷口膨脹一格，數它碰到幾個相異的預測連通塊——
≥2 是 `severs`（真切斷），1 是 `intact`（兩側繞得過去），0 是 `absent`。

同一個事件（斷口的像素有沒有被覆蓋），同一個半徑 6：

| 母體 | n | 被覆蓋 |
|---|---|---|
| 全部斷口 | 70,035 | 14.4%（重現 E10 的 14.9%）|
| **只算真切斷** | 4,875 | **24.4%** |
| 只算 intact | 65,043 | 13.7% |
| 只算 absent | 117 | **0.0%** |

`absent` 那一列是 0.0%，一個都沒有——**附近沒有東西可以焊的斷口，任何半徑都搆不到。**
這是 P1 的機制本身，而且它在合成測試裡就先斷言過了。

再看「不再切斷」這個更寬的事件（下一節解釋為什麼它比覆蓋率寬）：

| 半徑 | 1 | 2 | 3 | 6 |
|---|---|---|---|---|
| 真切斷中被解決的比例 | 12.4% | 25.3% | 34.4% | **53.8%** |

（`intact` 與 `absent` 兩列在這張表上恆為 100%，因為它們本來就不切斷。
那不是發現，是定義。真正有資訊的只有 `severs` 那一列。）

## 2. P2：一比一，比預期準得多

| 半徑 | 每張圖的真切斷 | 每張圖被解決 | β₀ 誤差（焊接前） | （焊接後） | 下降 | 比值 |
|---|---|---|---|---|---|---|
| 1 | 20.3 | 2.5 | 22.1 | 19.6 | 2.5 | **0.99** |
| 2 | 20.3 | 5.1 | 22.1 | 16.7 | 5.5 | **0.94** |
| 3 | 20.3 | 7.0 | 22.1 | 14.6 | 7.5 | 0.93 |
| 6 | 20.3 | 10.9 | 22.1 | 9.9 | 12.2 | 0.89 |

**E9b 的 β₀ 好處，一個不多一個不少，就是被解決掉的切斷。**

這是 E10 的 `severs` 指標第二次、而且是獨立的一次驗證。
E10 用的是相關係數（0.456 對原始斷點數的 0.095）；
E11 用的是逐項記帳，而記帳能對上才是真的對上。

比值在大半徑往下掉（0.99 → 0.89），方向合理：
半徑 6 的閉運算也會把兩個本來就不含斷口的碎塊併起來，
那些也算進 β₀ 的改善，卻不在斷口的帳上。

## 3. P3：我的假說被推翻，E9b 的反而被平反

寫這個腳本時，合成測試逼出了第三個候選解釋。
**閉運算焊不起一條 1 px 寬的線上的斷口，不管半徑多大：**
膨脹在斷口的上下留了一個腰，侵蝕就從那裡咬回去。
E9b 的合成測試用的是 3 px 寬的環壁，所以沒撞到。

既然模型的斷口大多在最暗、最細的血管上（E2：81% 在 Q1），
血管粗細看起來比斷口長度更像是天花板的成因。寫進 P3，然後量：

只在**焊接前就切斷**的 4,875 個斷口裡比較（把 `intact` 算進來會讓每一格
自動變成「解決」，那是分母灌水）：

| 依長度（E9b 的解釋） | n | 解決率 | | 依粗細（我的解釋） | n | 解決率 |
|---|---|---|---|---|---|---|
| 1 px | 312 | **74.0%** | | ≤2 px | 1913 | 48.9% |
| 2 px | 399 | 70.2% | | 3 px | 1005 | 57.3% |
| 3–6 px | 1355 | 68.6% | | 4–5 px | 1502 | 57.2% |
| 7–12 px | 1178 | 51.1% | | 6+ px | 455 | 55.8% |
| 13+ px | 1631 | **35.7%** | | | | |
| **跨格差距** | | **38.3 點** | | **跨格差距** | | **8.4 點** |

**長度贏，而且贏很多。** 粗細效應在合成測試上是真的，在真實資料上幾乎不重要。

所以 E9b 那句「剩下的是比兩倍血管寬還大的斷口」**是對的**——
搆不到的切斷有 46.6% 長度在 13 px 以上，而血管中位寬只有 2.83 px。

### 那 E10 推翻的是什麼

E10 的反駁仍然成立，只是範圍要說清楚：

- **E10 對**：拿**全部斷口**的長度分布去預測關閉率，會錯五倍。
- **E9b 也對**：在**真切斷**這個子母體裡，長度確實排得出解決率。

差別在母體。93% 的斷口本來就不需要被關（兩側已經連通），
把它們算進分母，長度分布當然預測不了任何事。
E9b 的推理沒錯，錯在套用在錯的母體上。

這在本系列裡是少見的一次：**一個被推翻的說法，在限定範圍後被平反。**

## 4. 意外收穫：一半的修復發生在別的地方

「被覆蓋」和「不再切斷」是兩個事件，而它們的數字差很多
（24.4% 對 53.8%）。差在哪裡：

| 斷口長度 | 解決率 | 其中被直接焊起來 | 其中是別處重新連上 |
|---|---|---|---|
| 1 px | 74.0% | **95.7%** | 4.3% |
| 2 px | 70.2% | 91.8% | 8.2% |
| 3–6 px | 68.6% | 57.6% | 42.4% |
| 7–12 px | 51.1% | 22.4% | 77.6% |
| 13+ px | 35.7% | 7.0% | **93.0%** |
| **全部** | **53.8%** | **45.3%** | **54.7%** |

**短斷口是被焊起來的；長斷口是兩端的連通塊在別的地方接上了。**

整體而言，焊接**超過一半的 β₀ 好處，來自跟被修好的那個斷口毫無關係的位置**。

這解釋了為什麼 13 px 以上的斷口在半徑 6 之下還有 35.7% 會解決——
它們沒有被焊起來（只有 7.0% 被覆蓋），是繞道通了。
也解釋了為什麼從斷口尺寸推天花板一定會低估：
那個推理假設焊接只能修它搆得到的那個斷口。

## 5. 修正後的說法

| 主張 | 狀態 |
|---|---|
| 焊接的 β₀ 好處 = 被解決的切斷數 | **成立**，比值 0.89–0.99 |
| 附近沒有預測結構的斷口搆不到 | **成立**，0/117 |
| 搆不到的切斷主要是長斷口 | **成立**，46.6% 在 13 px 以上（E9b 平反）|
| 血管太細是天花板的主因 | **不成立**，跨格差距 8.4 點對長度的 38.3 點 |
| 焊接修的是它搆得到的那個斷口 | **不成立**，54.7% 的解決發生在別處 |
