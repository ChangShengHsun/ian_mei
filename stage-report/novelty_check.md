# 這兩個有效的東西，是不是別人已經做過了

2026-08-28。文獻查證，不吃 GPU。查的對象定義如下，先寫清楚才查：

- **`G_focal`（信心閘）** = clDice（Shit et al., CVPR 2021），但 soft-clDice 的
  precision / sensitivity 兩個比值裡的**每一項**都乘上逐像素權重
  `w = 1 + γ(1 − 2|p − 0.5|)`，其中 `p` 是模型自己的預測機率，且 `detach()`。
  三個要素：**權重進入 clDice 內部**、**訊號只來自模型自身信心（不看標籤）**、**detach**。
- **`clw`（D-E）** = `BCE(logits, target, weight = 1 + w · skeleton_GT)`，
  真實中線像素在 BCE 裡加權，疊在原本的損失上。

為什麼要查：E7 曾宣告「權重來自影像端沒人做過」，2026-08-24 重查發現
Smooth clDice 佔著第三格。同樣的錯誤犯在核心貢獻上，論文就沒了。

## 結論一：`clw` 有前人做過，不能當貢獻

**Skeleton Recall Loss，ECCV 2024**（arXiv:2404.03010）。

```
L_SkelRecall = − (1/|C|) Σ_c  Σ_i Y_skel,i,c · Ŷ_i,c  /  Σ_i Y_skel,i,c
```

機制：在 CPU 上對真實標籤做 binarize → skeletonize → 用半徑 2 的菱形核膨脹成
「管」→ 得到 `Y_skel`，然後把這個 soft-recall 項加在 CE + Dice 上面。

跟 `clw` 對照：

| | Skeleton Recall (ECCV 2024) | 我們的 `clw` |
|---|---|---|
| 骨架從哪來 | 真實標籤，CPU 預先算 | 真實標籤，CPU 預先算 |
| 怎麼用 | soft recall 比值 | BCE 的逐像素權重 |
| 加在哪 | 疊在 CE + Dice 上 | 疊在原本的損失上 |
| 動機 | 讓模型蓋住真實中線 | 讓模型蓋住真實中線 |

**同一個想法、同一組材料，只有函數形式不同。** `clw` 最多是一個已知損失的變體。
它可以當 ablation 或 baseline，**不能當貢獻**。

## 結論二：`G_focal` 那一格目前沒被佔，但四周都住滿了

查到的鄰居，以及它們跟我們差在哪：

| 工作 | 權重進 clDice 內部？ | 訊號來源 | 需要標籤？ |
|---|---|---|---|
| **cbDice / cl-X-Dice**（MICCAI 2024） | **是** | 血管半徑（幾何） | 是 |
| **Smooth clDice**（LRDE tech report 2025） | **是** | 標註不確定帶（幾何） | 是 |
| **topohpm**（BMVC 2023） | 否，另加一個 BCE 項 | 二值挖掘：漏掉的真實骨架 ∪ 幻覺的預測骨架 | **是** |
| **TAFL**（CVPRW 2023） | 否，`α·L_focal + λ·L_topo` 相加 | focal，留在像素損失裡 | 是 |
| **PGU / REH**（Eng. App. AI 2025） | 否，加在 CE 和 Dice 上 | `μd + p`，`d = y − p` | **是** |
| **Gupta et al.**（NeurIPS 2023） | 否 | 拓樸不確定度是**輸出**，給人工校對用 | — |
| **我們的 `G_focal`** | **是** | `1 − 2\|p − 0.5\|`，只看模型 | **否** |

兩條軸讓我們的格子空著：

1. **訊號只來自模型信心，完全不看標籤。** topohpm 的挖掘要比對真實骨架；
   PGU 的 `d = y − p` 直接吃標籤。我們的權重可以在沒有標籤的像素上算出來。
2. **權重進入拓樸項內部。** TAFL 把 focal 留在像素損失、拓樸項另計；
   topohpm 另加一個 BCE。cbDice 和 Smooth clDice 確實進了 clDice 內部，
   但它們的權重是**幾何量**，不是模型狀態。

`topohpm` 的原始碼是直接讀的（`regularizer/skeletonloss.py`），不是靠摘要：
它用 `pred > filter_p` 二值化後跟真實骨架做 XOR/AND 得到一個**硬性的像素集合**，
再對那個集合算 plain BCE。**硬選集合 vs 連續權重**、**誤差訊號 vs 信心訊號**，
兩處都不同。

## 誠實的評估

那一格空著，但它是一個**擁擠網格裡的空格**，不是一個新的網格。
審稿人完全可以說：不確定度加權損失有了（PGU）、拓樸的難像素挖掘有了（topohpm）、
加權 clDice 有了（cbDice）—— 你只是把它們組起來。MICCAI 就是會因為這個拒稿。

撐得住的地方是**對照實驗**，不是損失本身：

- `F_gated`（影像端權重）vs `G_focal`（模型端權重），**權重範圍相同、其餘完全相同**。
  這個對照沒人跑過。
- 而且結果跟我們自己的事前預測**相反** —— 模型端贏了。
  E1' 量到模型信心在最暗的一層 AUROC 只有 0.373，據此預測模型端會失敗；
  它反而在 ERL 上 +664.1、t=5.17、六顆種子過閘。

所以比較誠實的定位是：**貢獻不是「我們發明了一個損失」，而是「我們量出這些損失
真正買到什麼，並且控制了一條沒人控制過的軸」。**
