## 0. 初版的五處修正

查證之後有五個地方必須改口。這一節放在最前面，因為其中兩項直接影響我們要跑的實驗。

### 0.1 連通塊過濾不是沒人用，是沒人拿它當對照組

初版寫「那一行後處理沒有出現在任何一篇我們讀過的論文的對照表裡」，
語氣暗示這是個被忽略的技巧。這是錯的。

連通塊過濾在應用型流程裡是**標準後處理**。搜尋到的實例包括：
血管分割中移除小於 10 個體素的連通塊、移除小於 100 個體素的前景物件、
肺血管分割用連通元件分析剔除肺遮罩外的離群塊 [verified via search]。

**正確的說法是**：它是常識，但在拓樸 loss 的論文裡，對照組通常是「未過濾的 baseline」，
而不是「baseline 加過濾」。stage 0 的 2.3 節仍然成立，
只是它揭露的是**對照組選擇的問題**，不是一個沒人知道的技巧。這個區別很重要，
因為前者是方法學批評，後者會被一眼看穿是文獻沒讀夠。

另外，「用學習出來的模型做連通性修復」本身也是一條在走的研究線
（arXiv:2404.10506 學習式後處理修復血管連通性、arXiv:2408.12943 即插即用的重連正則化）
[verified via search]。

### 0.2 TopoMortar 的結論比我寫的溫和

初版寫「TopoMortar 證明很多拓樸 loss 的增益可能被高估」。實際結論是兩句話：

1. **clDice 仍然拿到最高的拓樸準確度**，其他 loss 的相對優劣視實驗設定而定。
2. 資料增強與自蒸餾可以把 Cross-entropy + Dice **推過大多數（不是全部）拓樸 loss**，
   而且這些簡單方法同樣能增強拓樸 loss 本身。

[verified: https://arxiv.org/abs/2503.03365，BMVC 2025]

所以正確的表述是：簡單方法能追上大部分拓樸 loss，但 clDice 在受控條件下仍是最強的那一個。
初版把 clDice 也算進「被高估」的名單裡，這是誤讀。

### 0.3 基礎模型失敗的機制，論文講的跟我們轉述的不同

初版沿用 survey 的說法，把 SAM 的失敗歸因於「ViT 的 patch 比血管粗，資訊在 tokenize 時被平均掉」。

查了原文之後，論文自己給的機制是：
「SFM 把局部結構誤判為全域紋理，導致過度分割，或難以把物件跟相似的背景區分開來。」
測試的模型是 SAM、SAM 2、HQ-SAM（不含 MedSAM），提出的兩個可解釋指標是
**物件的樹狀程度（tree-likeness）**與**紋理可分性（textural separability）**。

不過關於微調的那句話是完全成立的，原文寫得比我們轉述的更重：
「Notably, targeted fine-tuning fails to resolve this issue, indicating a fundamental limitation.」

[verified: https://arxiv.org/abs/2412.04243，論文名為
*Quantifying the Limits of Segmentation Foundation Models: Modeling Challenges in
Segmenting Tree-Like and Low-Contrast Objects*，作者 Zhang, Konz, Kramer, Mazurowski]

「patch 比血管粗」是另一條獨立的論證線（來自 patch 尺度定律 arXiv:2502.03738），
兩者互相支持但不是同一篇的主張。以後引用要分開講。

**順帶一提，這篇跟 stage 0 有一個很漂亮的呼應**：他們的兩個軸是「樹狀程度」與「紋理可分性」，
而我們在 2.5 節做的正是把這兩個軸解耦，發現對比（≈紋理可分性）主導，
而粗細（≈樹狀程度的代理）在控制對比之後幾乎沒有影響。
他們證明兩者都與失敗相關，我們證明其中一個是混淆變項。這是可以接續的關係。

### 0.4 多標註者學習是成熟子領域，不是空白

**這一項直接影響我們的實驗規劃。** 初版把「用共識標註訓練」列為 E3，
以為那是從 stage 0 的 22 倍發現自然長出來的新題目。查證結果是這個領域已經很成熟：

| 工作 | 內容 |
|---|---|
| Learning from multiple annotators for medical image segmentation（Pattern Recognition 2023） | 兩個耦合 CNN 同時學「每位標註者的可靠度」與「專家共識標籤分布」 |
| A Soft Label Method for Medical Image Segmentation with Multirater Annotations | 用多評分者平均得到的全機率分布當軟標籤 |
| SoftSeg（arXiv:2011.09041） | 系統性比較軟標籤與二值訓練的優劣 |
| Learning robust medical image segmentation from multi-source annotations（MedIA 2025） | 指出標註者間變異蘊含的共通性與差異性在融合過程中被丟掉了 |
| Harmonized Feature Conditioning and Frequency-Prompt Personalization for Multi-Rater Medical Segmentation（arXiv:2605.08210, 2026-05） | 多評分者的個人化建模 |

[全部 verified via search]

而且這條線已經有明確的共識：**用標籤融合得到二值遮罩會抹掉標註者間變異，
而那個變異本身帶有可用於模型校準的資訊。**

所以「用軟標籤訓練」不是新想法，我原本的 E3 設計等於是在重做別人做過的事。
**還留著的空缺是它跟拓樸的交集**：既有的多評分者文獻幾乎都在談不確定度校準與 Dice，
我沒有找到有人問「在標註者分歧的前提下，拓樸指標會怎麼變」。
E3 必須往這個方向重寫，見第 5 節。

### 0.5 拓樸感知的不確定度已經有人做了

**這一項打到我們的 E1。** NeurIPS 2023 有一篇
*Topology-Aware Uncertainty for Image Segmentation*（arXiv:2306.05671），
明確針對曲線結構（血管、道路），用**離散莫爾斯理論（discrete Morse theory）**
先把結構抓出來，再以「拓樸結構為單位」估計不確定度，
目的正是讓高風險的連接與分支被標示出來給人類複核 [verified via search]。

我試著載入原文確認它是否用「多位標註者的實際分歧」來驗證那些不確定度，
抓到的摘要沒有寫明，只說用了「多個 2D 與 3D 資料集」。
**這一點還沒查清楚，先標為 `[unverified]`。**
如果他們沒做這個驗證，那 E1 仍有空間；如果做了，E1 就要退回成一個複現實驗。
下一步應該直接讀那篇的實驗章節。

## Q1 · 這個領域下一步想做什麼

先講定位。這不是空白領域，是一個成熟但卡在明確瓶頸上的領域，
瓶頸從 2019 年之後沒變過：血管只有 1 到 3 像素寬，Dice 感覺不到它斷掉。

依「擁擠程度」與「剩餘空間」排列，六條線的現況如下。

### 1. 把拓樸約束做便宜（最擁擠，已飽和）

代數拓樸路線（persistent homology、Betti Matching）數學最嚴謹，
但是全域、序列式演算法，難以平行化，3D 要自寫 C++ 才勉強可用。
近三年主線是加速：Topograph（ICLR 2025）用連通元件圖找關鍵區域，宣稱比 PH 快 5 倍；
Skeleton Recall Loss（MICCAI 2024）只對真值骨架化，可離線在 CPU 預算，省約 90% 計算
[verified via search]；TopoSegNet 走 critical points 路線。

**判斷不變：這條線已進入微幅改良期。** 想靠再發明一個 loss 進頂會，門檻很高。

### 2. 把寬度折進拓樸約束（初版說是空缺，其實已經有人佔位）

初版寫「便宜 + 管徑感知 + 有保證目前無解」，這句話要修正。
**cbDice（MICCAI 2024，arXiv:2407.01517）已經是一個成熟的答案**：
它把血管骨架的半徑資訊納入，讓 loss 對管徑變化一致適應，
在 2D 與 3D、二元與多類別共三個血管資料集上驗證，
並在 MICCAI 2023 TopCoW 挑戰資料上表現突出。**而且有公開程式碼**
（github.com/PengchengShi1220/cbDice）[verified via search]。

所以現在的空缺比初版寫的窄：cbDice 便宜且管徑感知，但**沒有形式化的拓樸保證**
（它是幾何近似，不是代數拓樸）。真正還缺的是「便宜 + 管徑感知 + 有保證」三者兼具，
而 2026-01 的 arXiv:2601.11409 是唯一的嘗試，代價是引入 PDE 求解器且未經審查。

**實務含義**：如果我們要做管徑相關的實驗，cbDice 必須是對照組，不能忽略它。

### 3. 對抗標註噪聲與標註稀缺（正在升溫，我們最靠近的一條）

所有拓樸 loss 都預設真值骨架是對的，但 1 像素寬的結構在標註者之間根本不一致。

2025 到 2026 這條線明顯活躍：
CurvSegFlow（arXiv:2606.21608）用時間條件流匹配處理噪聲與不完美標註；
YoloCurvSeg 只用一條有噪聲的骨架標註達到全監督 97% 效能；
MICCAI 2025 有 SAM-OSLN，把微調過的 SAM 當偽標籤產生器並降低開放集標籤噪聲，
直接針對視網膜血管的標註稀缺問題 [verified via search]。

再加上 0.4 節列的整套多評分者文獻，這條線其實比初版描述的擁擠得多。

### 4. 圖表示（技術上最有前途，競爭最激烈）

直接輸出圖而非像素遮罩，連通性由輸出格式保證。
Relationformer（ECCV 2022）、GraphMorph（NeurIPS 2024）是代表。
障礙是需要圖形式的真值，而多數資料集只有像素遮罩。

### 5. 領域專用基礎模型（新主戰場，2025 之後明顯加速）

通用基礎模型在細長結構上是死路（見 Q2），但領域專用的不是。
vesselFM（CVPR 2025）是 3D 血管專用模型。
眼底這邊 **RETFound** 已經是既成事實：用 masked autoencoder 在 130 萬張自然影像
加 160 萬張視網膜影像上預訓練；FunduSegmenter 是第一個把 RETFound 用於視網膜影像分割的工作，
報告幾乎全面超越 SOTA baseline [verified via search]。

**注意這改變了 Q2 的答案結構**：「不要用大模型」在通用模型上成立，
但視網膜領域現在有自己的基礎模型，這個選項已經真實存在。

### 6. 量測與資料品質（最被忽略，也最容易切入）

見 Q3。這條線的論文正在變多，而且拿得到好 venue。
另外有一個對我們特別重要的發現，放在 Q4 講。

### 小結

初版說「最值得押第 3 與第 6 條的交集」。查證後這個判斷**方向不變但難度上修**：
第 3 條比我原本以為的擁擠很多。真正還空著的是**第 3 與第 6 條再交上拓樸**，
也就是「當標註本身不可靠時，拓樸指標該怎麼報、目標值該定在哪」。
stage 0 的 2.6 與 2.7 節就是這個位置的初步證據。

## Q2 · 為什麼不直接拿大模型或大型影像辨識模型來跑

四個理由，強度由強到弱。查證後有一個理由要削弱，一個要加強。

### 1. 通用分割基礎模型在細長結構上是架構性失敗，微調救不回來

這是有直接證據的結論。arXiv:2412.04243 用可解釋的
「樹狀程度」與「紋理可分性」兩個指標，在受控合成實驗與真實資料上證明
SAM、SAM 2、HQ-SAM 的效能與這兩個因素明顯相關，
失敗機制是**把局部結構誤判為全域紋理**，造成過度分割或無法與相似背景區分。

原文對微調的表述是：
「targeted fine-tuning fails to resolve this issue, indicating a fundamental limitation.」
[verified: arXiv:2412.04243]

補充的獨立論證：ViT 把影像切成 14×14 或 16×16 的 patch 再 tokenize，
一條 2 像素寬的血管在一個 16×16 patch 裡只佔約 1% 面積；
arXiv:2502.03738 實證了 patch 越小效能越好，也就是 patch 化本身是有損壓縮 [unverified，需自行複查]。

這種失敗有一個危險性質：**它不表現為低信心**。模型不是不確定，而是根本沒有那個表示。

### 2. 我們的瓶頸不是模型容量（stage 0 的直接證據，且有外部佐證）

一個 11.7 萬參數的模型就達到 Dice 0.811，接近公認的 0.82 到 0.84 天花板。
更關鍵的是 stage 0 的 2.6 節：高對比區模型偵測率 99.7%，人類一致率 99.4%。
看得見的部分已經解決了。

**這一點現在有外部佐證。** 一篇跨資料集與跨疾病的視網膜血管分割 benchmark
（arXiv:2406.14994，用 FIVES 資料集測五個已發表模型）的結論是：

- 影像品質是決定分割結果的關鍵因素
- 資料量足夠時，**基本的 U-Net 與更先進的模型表現相當**
- 「投資在一個仔細整理過的資料集上訓練標準架構，效果好過在較小或品質較差的資料集上
  調一個複雜架構」

[verified: https://arxiv.org/abs/2406.14994]

這幾乎是 stage 0 的獨立重現，只是他們用「影像品質」，我們用「局部對比」。

### 3. 下採樣是所有大架構的共同敵人

模型越大通常下採樣層數越多，1 像素寬的結構在第一次縮小就有機會消失。
不過這條理由是機制推論，不是實測，強度中等。

### 4. 資料量與實驗經濟學

DRIVE 只有 20 張訓練影像。nnU-Net Revisited（MICCAI 2024）的結論是
SOTA 配方仍是 CNN-based U-Net 加 nnU-Net 框架加把模型放大到現代硬體，
而許多宣稱勝過 U-Net baseline 的說法在嚴謹檢視下站不住 [verified via search]。

還有一點：**便宜讓你買得起統計顯著性。** stage 0 的 20 次訓練跑在筆電 CPU 上共 20 小時。
那個 22 倍的發現需要 8 次訓練才成立。每次要 3 天 GPU 的話這實驗不會被做。

### 誠實的反面（查證後這一段要加重）

初版的反例太弱。現在有三個實質反例：

1. **極低資料量下大模型仍有優勢。** 僅 5 張標註時，SAM 系方法比 nnU-Net 高約 6.3 個 Dice 點
   [verified via search]。
2. **視網膜已經有自己的基礎模型。** RETFound 加 FunduSegmenter 的組合報告幾乎全面超越
   SOTA baseline。這不是「未來可能」，是已發表的結果。
3. **大模型可以當標註工廠而不是分割器。** MICCAI 2025 的 SAM-OSLN 用微調過的 SAM
   產生偽標籤來緩解標籤稀缺，這是一個繞開架構限制的用法。

**修正後的說法**：通用視覺分割基礎模型的表示與次-patch 寬度的結構不相容，這是架構層次的限制；
但領域專用基礎模型與「用大模型產生標註而非產生分割」這兩條路都是真的，
而且在 2025 之後成長很快。我們選小模型是因為**實驗經濟學**，不是因為大模型一定輸。

## Q3 · 大家是不是都在找更好的方法打 benchmark

大致上是，而且這件事已經被領域內部點名，力度比初版寫的更強。

### 現況：比較方式不可信

同一個資料集名稱底下，不同論文用不同切分、不同 FOV 處理、不同指標實作。
STARE 根本沒有官方切分。拓樸類指標每一個都不到 3 歲，沒有一個成為必填欄位。

### 反抗的力度比初版描述的大

**nnU-Net Revisited（MICCAI 2024）** 的原話值得完整記下來：
許多近期宣稱勝過 U-Net baseline 的說法，在檢視常見的驗證缺陷之後站不住，
這些缺陷包括**不足的 baseline、不足的資料集、以及被忽略的計算資源差異**。
他們的結論是這個領域存在**「對新架構的創新偏誤（innovation bias）」**，
需要更嚴格的驗證標準 [verified via search]。

配套的還有 nnWNet（2025）呼籲統一評估 benchmark、
U-Bench 用 100 個 U-Net 變體做系統性比較。

### TopoMortar 的正確版本

見 0.2 節。摘要一次：clDice 在受控條件下仍是拓樸最準的，
但資料增強與自蒸餾可以把普通的 CE + Dice 推過**大多數**拓樸 loss。
含義是「很多拓樸 loss 的增益可以被更簡單的方法取代」，而不是「clDice 沒用」。

### stage 0 的定位（修正後）

我們的 2.3 節不是發現了一個沒人知道的技巧，而是**示範了對照組選擇如何改變結論**。
連通塊過濾是應用端常識，但拓樸 loss 論文的對照組通常是未過濾的 baseline。
在 DRIVE 上，補上這個對照組之後 clDice 的優勢從 22% 掉到 6.7%，
逐張比較從 20 比 0 掉到 10 比 10。

這跟 TopoMortar 的教訓同型，只是我們的對照組更便宜（一行後處理，不需要重訓）。

### 結論

是的，主要在打 benchmark，而 benchmark 有結構性問題，
**而且領域內部已經有一群人在說這件事，並且拿得到 MICCAI 與 BMVC oral。**
這降低了做這類工作的風險：不是逆風而行，是搭上一個正在成形的共識。

## Q4 · 我們可以做哪些事情來提升成功率

條件：一台筆電 CPU、沒有 GPU 叢集、沒有標註預算、beginner 程度的工程能力。

### 策略不變，但理由更強了

不要比分數，比量測與診斷。查證之後這個策略多了三個支撐：

1. nnU-Net Revisited 明說領域存在「對新架構的創新偏誤」，需要更嚴格驗證。
2. 跨資料集 benchmark（arXiv:2406.14994）的結論是**整理資料勝過調架構**。
3. TopoMortar 用一個受控資料集就進了 BMVC oral，證明這類工作的天花板不低。

也就是說，「做量測」現在是一條有前例、有共識、而且不需要算力的路。

### 六個具體做法（修正版）

**1. 對照組要選對，而且要說明為什麼選它。**
任何拓樸方法都要跟「baseline 加連通塊過濾」比。
但論文裡不能寫成「我們發現了一個沒人用的技巧」，要寫成
「應用端的標準後處理，在方法比較中通常沒有被納入對照」，並引用實際使用它的工作。

**2. 報分層指標，不要報單一數字。**
依局部對比切層分別報。stage 0 顯示方法間差異幾乎都發生在專家也不同意的那一層。
這一項我還沒找到有人做過，是目前最有可能是真空的一個。

**3. 把標註來源當一級實驗變因。**
影響是 loss 選擇的 22 倍。優先選有多標註者的資料集：STARE（已下載）、CHASE_DB1、CORN。
但要注意 0.4 節：多評分者建模本身已經很成熟，我們的角度必須是**拓樸**，不是不確定度校準。

**4. 用受控合成資料隔離混淆。**
TopoMortar 的做法可以直接抄，而且他們的資料集是公開的，可以先在上面複現我們的過濾實驗。

**5. 選對投稿場域。**
MICCAI、MIDL、Medical Image Analysis 優於 CVPR。TopoMortar 進 BMVC oral 是前例。

**6. 診斷要配一個最小的方法改動。**
純分析論文的風險是被嫌貢獻不足。緩解方式是提出一個由診斷直接推導出的最小改動，
並證明它只在診斷預測的地方有效。

### 兩個要避免的陷阱

**第一，不要停在負面結果。** 它要成為論文需要機制解釋、受控驗證、可操作建議三件事。

**第二，也是這次查證最大的教訓：先查文獻再設計實驗。**
初版規劃的五個實驗裡有兩個（E1、E3）撞到既有工作。
如果直接開跑，會浪費約 22 小時的運算，還會得到一個沒有貢獻的結果。
**以後每一個實驗在開跑之前，都要先花半小時查「有沒有人做過」，並把查到的東西寫進實驗設計裡。**

## 接下來要跑的實驗（修正版）

初版的五個實驗中，E1 與 E3 因為 0.4 與 0.5 節的發現需要重新定位，
E2、E4、E5 維持不變但補上了對照組要求。依成本由低到高排列。

### E0 · 讀完那兩篇撞題的論文（前置，不需運算）

在動任何實驗之前，先讀 arXiv:2306.05671 的實驗章節，確認它是否用實際的標註者分歧
驗證不確定度；再讀 Pattern Recognition 2023 那篇多標註者論文的實驗設定，
確認它是否報告過任何拓樸指標。

**驗收**：兩個問題各給一個明確的是或否，附章節或圖表編號。
這兩個答案決定 E1 與 E3 是不是還值得做。

**成本**：約 2 小時閱讀。

### E1' · 拓樸不確定度對得上人類分歧嗎（視 E0 結果而定）

**修正後的問題**：既有的拓樸不確定度工作（arXiv:2306.05671）是否驗證過
「模型的不確定度落在人類真的會吵架的地方」？如果沒有，我們用 STARE 的兩位標註者補這個驗證。

**做法**：在 STARE 上取既有模型的 sigmoid 機率圖，
計算「機率接近 0.5 的程度」與「ah 和 vk 是否不一致」的相關性，依對比分層報告。
若 E0 顯示對方已做過同樣驗證，本項退化為複現，優先度降到最後。

**驗收**：分層相關係數表。若 Q1 層的相關顯著高於 Q4 層，代表模型的猶豫與人類的猶豫落在同一處。

**成本**：約 1 小時，不需訓練。

### E2 · 對比分層的評估協定（維持，目前最可能是真空的一項）

**問題**：把 stage 0 全部 12 個 DRIVE 模型的結果依對比分層重報，四種 loss 的排序會不會改變？

**做法**：對既有模型，把 Dice、clDice、β₀ 依對比四分位分別計算，
並且**同時報過濾前與過濾後**，共 4 loss × 4 對比層 × 2 過濾狀態。

**驗收**：完整指標表，明確回答「這些方法的差異是否全部發生在低對比層」。

**為什麼優先**：查證中沒有找到有人對曲線結構做過對比分層的指標報告。
這是目前手上最可能沒被做過的一件事，而且完全不需要算力。

**成本**：約 2 小時，不需訓練。

### E3' · 標註者分歧對拓樸指標的影響（重新定位）

**初版的錯誤**：原本要比較「聯集、交集、軟標籤」哪個訓練目標好。
這在多評分者文獻裡已經被做爛了（0.4 節）。

**修正後的問題**：既有多評分者文獻談的是不確定度校準與 Dice。
**沒有人問過：當訓練目標從一位標註者換成另一位，拓樸指標會怎麼變？**
stage 0 的 2.7 節已經有 Dice 的答案（差 0.097），但 β₀ 的部分我們只有粗略數字
（ah 訓練對 ah 是 26.6、對 vk 是 22.8；vk 訓練對 vk 是 30.7、對 ah 是 34.7），
還沒有依對比分層，也沒有跟軟標籤比。

**做法**：在既有 8 個 STARE 模型上，先把拓樸指標依對比分層重報（免費）。
如果分層後看到訊號，再加訓一組軟標籤模型（兩人都標為 1.0，只有一人標為 0.5）作為第三個對照。

**驗收**：先產出「訓練來源 × 評分對象 × 對比層」的 β₀ 表。
再決定要不要花 10 小時加訓軟標籤組。

**成本**：分層重報約 2 小時；若要加訓，額外約 10 小時。

### E4 · 過濾發現的跨資料集驗證（維持，補一個對照組）

**問題**：「過濾贏過 clDice loss」只在 DRIVE 成立，還是普遍現象？

**做法**：加入 HRF（45 張，高解析）與 CHASE_DB1（28 張，2 位標註者）。
高解析資料的過濾門檻要依血管寬度縮放，不能沿用 20 px 這個絕對值。
**新增要求**：這次要把 cbDice 也納入對照組（0.2 節，有公開程式碼），
否則會被質疑只跟最舊的方法比。
另外可以直接在 TopoMortar 的公開資料集上複現一次，那是為此設計的受控資料。

**驗收**：三到四個資料集上「過濾帶來的改善」與「拓樸 loss 帶來的改善」的比值。

**風險**：CHASE_DB1 官方頁前次連線被 403 擋掉，需另尋鏡像；拿不到就只做 HRF 加 TopoMortar。

**成本**：約 1 到 2 天。

### E5 · 受控標註噪聲實驗（維持，但要先看 TopoMortar）

**問題**：拓樸 loss 是否比 Dice 更容易被標註噪聲帶壞？

**注意**：TopoMortar 已經內建三種標籤（準確、偽標籤、噪聲標籤），
所以這個實驗應該先在 TopoMortar 上做，而不是自己在 DRIVE 上造噪聲。
自己造噪聲的公平性很難辯護，用別人設計好的受控資料集省事也更有說服力。
我們的增量是**依局部對比調整噪聲強度**，模擬 stage 0 量到的「暗處標註較不可靠」。

**驗收**：噪聲強度對測試分數的曲線，四種 loss 各一條。
若拓樸 loss 下降較快，P2（拓樸 loss 假設真值骨架正確）就有直接證據。

**成本**：約 1 到 2 天。

### 順序

先做 **E0**，因為它決定 E1' 與 E3' 是否值得做，而且只要 2 小時。
接著做 **E2**，它免費、當天有結果、而且是目前最可能是真空的一項。
然後是 **E3'** 的免費部分（分層重報），依結果決定要不要加訓。
E4 與 E5 都需要新資料集，等前面三項確認方向之後再啟動。

**這個順序的原則是：先把不需要算力就能做完的事做完，再花算力。**
stage 0 最有價值的三個發現全部來自重新量測既有模型，不是來自訓練新模型。
