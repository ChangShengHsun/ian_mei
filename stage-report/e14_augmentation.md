# E14 · 改變「給模型看什麼」，而不是「要求模型什麼」

2026-08-21 排入佇列。六次訓練（`H_aug`、`I_coletra` × seed 0–2），約 9 小時。

**本報告第 0 到第 4 節寫在六次訓練啟動之前，一個結果都還沒有。**
判準同時寫進 `exp/summarize_augment.py`，該檔先跑過 `--selftest` 才排隊。

---

## 0. 一個尷尬的發現

查文獻查到 CoLeTra（[arXiv:2503.05541](https://arxiv.org/abs/2503.05541)，Valverde et al. 2025）
時，我去讀了它的表 1。DRIVE、DynUNet、CE loss 那一列是：

| 設定 | Betti 誤差 |
|---|---|
| baseline | 3.687 |
| **+ 資料增強** | **1.354** |
| + 資料增強 + CoLeTra | 1.282 |

論文的貢獻是最後那一步（1.354 → 1.282，約 5%）。
但中間那一步是 **63%**。

然後我去看我們自己的 `sample_batch`：**隨機裁切，沒有其他任何增強。**
沒有翻轉、沒有旋轉、沒有強度擾動。

也就是說，這個系列花了二十個實驗比較 loss，
而比較的對象是一個**連最基本的資料增強都沒有做**的管線。
E5 量到「乾淨標註下三個 loss 之間的差距小於同一個 loss 兩顆種子之間的差距」，
現在有一個更難堪的解釋候選：那個天花板可能根本不是 loss 決定的。

## 1. 兩個 arm

兩個都保持 BCE+Dice，**loss 一個字都不改**，只改給網路看的東西。

### `H_aug` — 標準資料增強

- **正方形的八個對稱**（旋轉 + 翻轉）。視網膜在 48 px 的貼片尺度上沒有正典方向，
  所以整個二面體群都可用。
- **gamma / gain / bias 擾動**。這一項是針對本系列自己診斷出來的病灶：
  E2 量到決定一條血管抓不抓得到的是**局部對比**，
  而 gamma 擾動正是在改變「這條血管有多明顯」。
  它是單調的，所以不會把兩個像素的順序調換——改變的是可見度，不是結構。

### `I_coletra` — 再加上 CoLeTra

論文的式 (1)：在隨機選中的前景像素 c 上，
把一個**被修補過（血管已移除）的**貼片以高斯權重混進原圖，
**標籤完全不動**：

```
x_p ← g(p,c,σ)·x̃_p + (1 − g(p,c,σ))·x_p
```

教的是一件先驗知識：**看起來斷掉的結構，其實是連著的。**

論文用 LaMa 做修補，並明說方法與修補器無關。
對「亮背景上的暗細線」而言，一次灰階閉運算就做到同一件事——
而 E7 的對比閘本來就在算那張圖（`grey_closing(image) − image` 的第一項）。
所以這一步對我們幾乎免費。

超參數照論文在 DRIVE 上的做法：貼片 15 px（論文掃 11/15/19），
數量選到覆蓋結構的 40–60%。**實測 56.4%**，寫成 `augment.py` 的一個斷言。

## 2. 一個沒有 loss 會抱怨的 bug

幾何變換必須同時作用在影像、標籤、距離圖上。
如果只轉了影像而沒轉標籤，模型會學到鏡像的目標，
而**任何 loss 都不會發出警告**——它只會安靜地變差。

所以檢查寫成精確的形式：餵一張「影像就是標籤本身」的資料，
經過整條批次取樣路徑之後，兩者必須仍然逐像素相等。

```
H_aug: image and label stay aligned through ('dihedral',)
I_coletra: image and label stay aligned through ('dihedral', 'coletra')
augmented batches differ from unaugmented ones
```

最後一行也是必要的：增強如果沒真的接上，這個 arm 就只是 baseline 換個名字。

## 3. 事前判準（在六次訓練啟動之前固定）

寫在 `exp/summarize_augment.py`。兩條既有規矩內建，都不可選：
**種子閘**（E5）與**真切斷計數**（E10）。

| | 判準 | 通過條件 |
|---|---|---|
| **1** | `H_aug` 在最暗一層的 Dice 贏 `A_dice` | 差值 > 0、t > 2、三顆種子全正 |
| **2** | `H_aug` 減少最暗一層的**真切斷**數 | 差值 < 0、t < −2、三顆種子全負 |
| **3** | `I_coletra` 在 `H_aug` 之上再減少真切斷數 | 同上 |
| **4** | `H_aug` 沒有賠掉最亮一層 | 非劣性 |

判準 2 是關鍵的那一條。E7 就是被它擋下來的：
那個 arm 每張圖少了 25 個斷口，真切斷卻一個也沒少。
**斷口數的 93% 在量中心線覆蓋率**，所以「拓樸改善」必須用 `severs` 講。

### 三種結果的預先解讀

| 結果 | 意思 |
|---|---|
| 1、2 都過 | 「給模型看什麼」勝過「要求模型什麼」。這會改變整個系列的優先順序 |
| 1 過、2 不過 | 增益是覆蓋率不是連通性。照那樣報，跟 E7 一樣 |
| 1 不過 | **先懷疑我們的設定，不要先相信結果**——這與已發表的 DRIVE 結果矛盾。第一件事是確認增強真的進到批次裡（`augment.py` 有那個檢查） |

## 4. 兩個限制，先寫下來

**一、我們的 baseline 不是論文的 baseline。**
他們用 DynUNet / AttentionUNet，我們是 11.7 萬參數的小 U-Net。
63% 這個數字不能直接套用到我們身上，只能當方向。
增強對小模型的幫助可能更大（它等於擴增了資料）也可能更小（模型撐不住更難的分佈）。

**二、這不會回答容量的問題。**
E13（把 base 從 16 拉到 32）仍然該跑。
先跑 E14 的理由只有一個：它便宜得多（每個 run 多 1.5–2.9 分鐘，
相對於 base=32 的每個 run 多 3 小時），而文獻上的槓桿更大。

## 5. 沒有跑的第三個候選：LIOT

[LIOT](https://arxiv.org/abs/2202.12587)（Shi et al., TIP 2021）把灰階影像轉成
**對比不變的四通道影像**：每個方向（左右上下）上，
比較中心像素與距離 1–8 的鄰居，大於記 1、否則記 0，
以 2ⁱ 加權後求和，得到 0–255 的 uint8。

它是三個候選裡**最直接打在我們診斷上的**——
我們量到失敗集中在低對比，而它從輸入端消除對比依賴。
E0 當時的查核也發現 LIOT **一個拓樸指標都沒報過**，所以那是個真空。

沒有現在跑，是因為它把輸入從 1 通道變成 4 通道，
要動 `stack_split`、`sample_batch`、`predict_full` 三處與正規化常數。
照最短差異優先的原則，先跑只動一個函式的兩個 arm。
LIOT 排在第二階段。

# 結果 · 2026-08-23

六次訓練於 08-23 06:40 跑完。以下每一節都寫在判準之後，判準沒有動過。

## 6. 判準結果：3 過 1 不過，而不過的那條不是失敗

```
[FAIL] 1. 最暗一層的 Dice 贏基線      +0.0228  t=6.06  每種子 +0.0166 -0.0021 +0.0540
[PASS] 2. 減少真切斷（不只是斷口）    -3.0000  t=-5.07 每種子 -3.45 -2.05 -3.50
[PASS] 3. CoLeTra 在增強之上再減少    -3.6000  t=-7.64 每種子 -3.80 -4.30 -2.70
[PASS] 4. 沒有賠掉最亮一層            -0.0022  t=-3.65
```

判準 2 是本系列**第一次有東西通過真切斷這條線**。
[[e7_contrast_gated]] 沒過，[[e12_confidence_gate]] 也沒過——兩個都是動 loss 的。
過的這個不動 loss，它動的是輸入。

判準 3 更乾淨：CoLeTra 在已經增強過的基礎上，還能再砍 3.6 個真切斷，三顆種子全負。
論文自己報的增益是 5%（1.354 → 1.282），我們在 β₀ 上量到 17%。

## 7. 全圖層級：本系列做過的介入裡最大的一個

最後一個 epoch 的驗證集平均：

| arm | 訓練 loss | Dice | clDice | β₀ 誤差 | β₁ 誤差 | HD95 |
|---|---|---|---|---|---|---|
| A_dice（基線）| 0.359 | 0.8112 | 0.8138 | 90.6 | 30.13 | 4.373 |
| **H_aug** | 0.431 | 0.8218 | 0.8318 | **63.4** | 27.23 | **3.662** |
| **I_coletra** | 0.426 | **0.8238** | 0.8308 | **52.6** | **26.02** | 4.634 |

**五個指標、三顆種子，H_aug 每一顆都贏 A_dice 每一顆。**
β₀ 掉 30%，HD95 掉 16%。
對照組：stage 0 量到四個 loss 之間的全圖 Dice 差 0.0002。

訓練 loss 從 0.359 升到 0.431，驗證指標卻全面變好。
這是增強真的進到批次裡的獨立證據——沒接上的增強不會讓訓練 loss 變難。
（`augment.py` 的對齊檢查也重跑過一次，全過。）

CoLeTra 買到的是 β₀ 再降 17%、β₁ 再降 4.4%，
**代價是 HD95 從 3.66 回到 4.63**。方向合理：它教的是「看起來斷掉的其實是連著的」，
那個先驗會鼓勵模型往外接，邊界精度就付了帳。
Dice 幾乎沒動（0.8218 → 0.8238），所以這是一次拓樸換邊界的交易，不是全面勝利。

## 8. 判準 1 為什麼不過：Q1 的種子變異，不是增強無效

逐種子、逐對比層對基線的差值（連通塊過濾後）：

| | Q1 最暗 | Q2 | Q3 | Q4 最亮 |
|---|---|---|---|---|
| H_aug s0 | +0.0166 | +0.0214 | +0.0018 | −0.0022 |
| H_aug s1 | **−0.0021** | +0.0228 | +0.0090 | +0.0017 |
| H_aug s2 | +0.0540 | +0.0195 | −0.0070 | −0.0059 |
| I_coletra s0 | +0.0210 | +0.0239 | −0.0004 | −0.0037 |
| I_coletra s1 | **−0.0031** | +0.0212 | +0.0059 | +0.0003 |
| I_coletra s2 | +0.0238 | +0.0257 | +0.0010 | −0.0027 |

**Q1 的種子間全距是 0.056；Q2 是 0.003。差了十八倍。**

所以事前寫下的「1 不過就先懷疑設定」這一條，執行之後的答案是：設定沒問題
（對齊檢查過、訓練 loss 上升、其他三層都穩），
問題在**判準 1 挑的那一層本身就是變異最大的一層**。

而且不能推廣成「Q1 天生就吵」——同一張表裡 `G_focal` 的 Q1 增益
（+0.0350 / +0.0313 / +0.0384，全距 0.007）穩得很。
是**增強在 Q1 的效果**依種子而定，不是 Q1 對任何介入都不穩。

## 9. 真正的發現在 Q2，而它不在判準裡

把三個介入放在同一張表上（對 A_dice 的差值，過濾後）：

| | Q1 | Q2 | Q3 | Q4 |
|---|---|---|---|---|
| G_focal | **+0.0349** | −0.0127 | −0.0136 | −0.0040 |
| H_aug | +0.0228 | **+0.0212** | +0.0013 | −0.0022 |
| I_coletra | +0.0139 | **+0.0236** | +0.0022 | −0.0021 |

**G_focal 是重新分配：Q1 的增益由 Q2、Q3、Q4 三層買單，三顆種子全部如此。**
**增強不是。它拿走 Q1 和 Q2，其他兩層幾乎不動。**

這是本系列第一個不是零和的結果。
從 [[e2_contrast_stratified]] 開始，每一次「某層變好」都伴隨「另一層變差」；
[[e15_expected_run_length]] 又量到 Q3/Q4 已經在天花板的 99%、Q2 在 85–89%。
所以 Q2 那 +0.021 是真的把剩下的空間吃掉了一塊，不是從別處搬過來的。

Q2 的增益通過種子閘通過得毫無懸念（+0.0214 / +0.0228 / +0.0195）。
**但它不是事前判準，所以它是探索性的**，
要按 [[e5_label_noise]] 的規矩另外跑種子確認，不能就這樣當結論用。

## 10. 這對整個系列的意思

第 0 節寫下的那個尷尬猜測成立了：
這個系列花了十幾個實驗比較 loss，比較的對象是一條沒有資料增強的管線，
而補上增強帶來的改善**比所有 loss 之間的差距加起來還大**。

不是說 loss 的實驗白做——E10 的真切斷、E5 的種子閘、E15 的 ERL 都還在，
而且正是那些工具讓這次的結論能講得比「Dice 高了 0.01」精確。
但優先順序要換：**先把輸入端的常識補滿，再談 loss。**

## 11. 三個限制

**一、判準 1 的失敗是真的失敗，不能當沒發生。**
事前寫的是 Q1，結果 Q1 沒過。第 9 節的 Q2 發現是事後找到的，
它的地位是「下一個實驗的假設」，不是本實驗的結論。

**二、CoLeTra 的 HD95 代價沒有事前預期。** 判準 4 只保護了最亮一層的 Dice，
沒有保護邊界指標。這是判準寫得不夠寬。

**三、只有三顆種子，只有 DRIVE。**
增強在小模型上的效果會不會隨資料集改變，這裡答不了。

## 14. Q2 撐住了，而且撐得非常好

第 9 節的 Q2 發現是事後找到的、標成探索性的。六顆種子之後：

| | Q1 | Q2 | Q3 | Q4 |
|---|---|---|---|---|
| H_aug s0–s5 | +0.0166 −0.0021 +0.0540 +0.0027 +0.0320 +0.0075 | **+0.0214 +0.0228 +0.0195 +0.0278 +0.0188 +0.0283** | | |

| I_coletra 平均 | +0.0052 | **+0.0253** | +0.0046 | −0.0006 |

**Q2 十二顆種子（兩個 arm × 六顆）全部為正，最小的是 +0.0188。**

它仍然不是事前判準，所以它仍然是探索性的——
但它現在是這個系列中種子一致性最高的效應，而且比通過了判準的那些都高。

## 15. 一個不能事後改的判準，和它的缺陷

判準 1 的閘是「每顆種子符號一致」。擋下它的 s1 是 **−0.0021**，
而通過的種子最大是 **+0.0540**——**符號閘看不到大小，這兩個對它一樣重。**

這是閘的真實缺陷。但**不能因此改判準**：
判準在六次訓練之前就固定了，看到結果之後放寬它，
就是這整個系列用事前登記在防的那件事。

所以：**判準 1 的結論是不成立**。
缺陷寫在這裡，作為**下一次**事前登記的輸入——
例如「每顆種子同號，或反向的那顆小於最大正向的 10%」，
但那要在下一個實驗開跑之前寫，不是現在。

## 16. 順帶量到的：Q1 上 clDice 比增強可靠

六顆種子的同一張表裡：

| Q1 比較 | 平均 | 種子閘 |
|---|---|---|
| B_cldice − A_dice | +0.0186 | **通過**（+0.0307 +0.0243 +0.0088 +0.0181 +0.0274 +0.0023）|
| H_aug − A_dice | +0.0185 | 不通過（−0.0021 那顆）|

**平均幾乎一樣，但 clDice 的六顆全正。**
所以「增強勝過 loss」這句話要限定範圍：
在全圖、在 Q2、在拓樸、在跨資料集轉移上都成立；
**在最暗那一層，clDice 的增益比較可靠，增強的比較看運氣。**
